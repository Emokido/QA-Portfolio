# TF-BUG-012 — 동행 모집 인원 필터가 잘못된 값과 역전 범위를 제한하지 않음

- 결함 상태: `Open — Product policy confirmation required`
- 발견 경로: 사용자 수동 프런트 탐색
- 기준 프로젝트: 스프린트 1 Java/Spring 완성본과 Next.js 프런트
- 기준 커밋: `e2431223ce2a18c8f944d544cba76b951ce0356d`
- 영향 기능: 동행 모집 인원 필터의 입력 경계·범위 관계
- 테스트 수준: Browser UI · 정적 코드 상관 분석
- 심각도: `Minor`
- 수정 우선순위: 제품 담당자 결정 필요
- 실행 주체: `User`

## 1. 요약

동행 모집 인원 필터가 음수, 소수, 최소 인원이 최대 인원보다 큰 값과 일부 비정상 숫자 문자열을 일관되게 제한하거나 설명하지 않는다. 소수 입력 검색에서는 모집글 조회 오류가 관찰됐다.

## 2. 원본 기록과 추적

- 수동 탐색 원본 번호: `BUG-004`
- 원본 발견 기록: 사용자 내부 자료로 보존하며 공개 산출물은 아래 정제 보고서를 사용한다.
- 수동 탐색 보고서: [TripFriend 수동 프런트 탐색 보고서](../reports/manual-frontend-exploration-report.md)

## 3. 테스트 환경

- Windows 11, Chrome
- Frontend `localhost:3000`, Backend `localhost:8080`
- 로그인 및 로그아웃 상태

## 4. 재현 변형

1. 동행 모집 목록에서 모집 인원 최소·최대 입력란을 찾는다.
2. 다음 입력을 각각 적용하고 검색한다.
   - 소수
   - 음수
   - 최소 인원 > 최대 인원
   - `--`, `124--54552` 같은 비정상 문자열
3. 입력 필드, 사용자 안내, Network와 결과 목록을 확인한다.

## 5. 기대 결과

제품이 허용하는 인원 범위를 명시하고, 정수·양수·최소/최대 관계를 검색 전에 일관되게 검증한다. 잘못된 값은 수정 방법을 안내하며 API 조회 오류 화면으로 전환하지 않는다.

## 6. 실제 결과

- 소수 입력 후 검색에서 모집글 조회 오류가 표시됐다.
- 음수를 입력할 수 있었고 별도 오류가 표시되지 않았다.
- 최소 인원이 최대 인원보다 큰 값을 허용했다.
- 일부 비정상 문자열은 빈 값처럼 처리되는 것으로 사용자가 관찰했다.

## 7. 코드 상관관계

- `frontend/src/app/recruit/list/ClientPage.tsx`의 두 필드는 `type="number"`지만 `min`, `step`과 필드 간 관계 검증이 없다.
- 검색 시 문자열을 `Number()`로 변환해 `minGroupSize`·`maxGroupSize`로 보낸다.
- `frontend/src/lib/api/recruit.ts`는 필터를 `/recruits/search3` 쿼리로 직렬화한다.
- 백엔드 `RecruitController.searchAndFilter`는 두 값을 `Optional<Integer>`로 받는다.

## 8. 영향과 심각도 근거

- 잘못된 필터 입력이 오류 또는 모호한 빈 값 처리로 이어져 사용자가 원인을 알기 어렵다.
- 정상 모집글 조회 전체가 차단되거나 데이터가 변경되지는 않아 `Minor`를 제안한다.

## 9. 수정 후 재검증 조건

- 허용 가능한 최소·최대 인원과 정수 단위 정책을 정의한다.
- 0·음수·소수·빈 값·정상 경계값을 확인한다.
- 최소값이 최대값보다 큰 경우 검색 요청 전 안내하는지 확인한다.
- 프런트와 백엔드가 같은 타입·범위를 사용하고 오류 응답을 화면에서 설명하는지 확인한다.

## 10. 확인 한계

- 유효 모집 인원 범위와 역전 범위 처리 정책은 명시된 요구사항에서 확인되지 않았다.
- 소수 입력 당시의 HTTP 401은 입력 변환 실패만으로 설명되지 않으므로 원인으로 단정하지 않는다. 저장된 인증 상태가 영향을 줬는지 재검증이 필요하다.
- 여러 입력 변형은 공통된 필터 검증 경계로 묶었으며 원인 분리 시 후속 결함으로 나눌 수 있다.
- Codex가 제품을 재실행하지 않았다.
