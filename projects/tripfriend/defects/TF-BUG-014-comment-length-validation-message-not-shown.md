# TF-BUG-014 — 댓글 길이 경계 위반 시 구체적인 입력 안내가 표시되지 않음

- 결함 상태: `Open`
- 발견 경로: 사용자 수동 프런트 탐색
- 기준 프로젝트: 스프린트 1 Java/Spring 완성본과 Next.js 프런트
- 기준 커밋: `e2431223ce2a18c8f944d544cba76b951ce0356d`
- 영향 기능: 인증 사용자의 댓글 작성 입력 검증·오류 안내
- 테스트 수준: Browser UI · 정적 코드 상관 분석
- 심각도: `Minor`
- 수정 우선순위: 제품 담당자 결정 필요
- 실행 주체: `User`, `Codex with user authorization`

## 1. 요약

로그인 사용자가 2자 미만 또는 100자 초과 댓글을 제출하면 허용 길이와 수정 방법을 알리는 대신 `댓글 작성 중 오류가 발생했습니다.`라는 일반 오류만 표시된다.

## 2. 원본 기록과 추적

- 수동 탐색 원본 번호: `BUG-006`
- 관련 요구사항: `TF-REQ-008` 댓글 CRUD, `TF-REQ-012` 댓글 2~100자 입력 경계
- 관련 위험: `TF-RISK-009`
- 원본 발견 기록: 사용자 내부 자료로 보존하며 공개 산출물은 아래 정제 보고서를 사용한다.
- 수동 탐색 보고서: [TripFriend 수동 프런트 탐색 보고서](../reports/manual-frontend-exploration-report.md)
- 자동화 재현: `TF-E2E-006 → TF-S8-PW-KD-EXEC-001·TF-S8-PW-KD-RETEST-001`

## 3. 테스트 환경

- Windows 11, Chrome
- Frontend `localhost:3000`, Backend `localhost:8080`
- 로컬 테스트 회원 로그인 상태

## 4. 재현 절차

1. 로그인한 뒤 커뮤니티 리뷰 상세 화면을 연다.
2. 1자 댓글을 작성해 제출한다.
3. 101자 이상 댓글을 작성해 제출한다.
4. 화면 안내와 Network 응답을 확인한다.

## 5. 기대 결과

댓글이 2자 이상 100자 이하이어야 한다는 안내가 표시되고 잘못된 입력은 저장되지 않아야 한다.

## 6. 실제 결과

- 1자·101자 두 경계 위반 입력에서 댓글 POST는 HTTP 400으로 거부됐지만 구체적인 길이 안내 대신 `댓글 작성 중 오류가 발생했습니다.`라는 일반 오류가 표시됐다.
- 101자 변형은 dialog 처리 교정 후 Codex 단일 재실행에서도 4.3초에 동일 Fail을 재현했고 fixture cleanup을 완료했다.

## 7. 코드 상관관계

- 백엔드 `CommentRequestDto.content`에는 `@NotBlank`와 `@Size(min=2, max=100)`가 선언돼 있다.
- 프런트 `review-detail.tsx`는 trim 후 빈 문자열만 사전 차단하며 길이를 검사하지 않는다.
- 댓글 생성 요청 실패를 catch하면 응답의 필드 오류를 해석하지 않고 일반 alert를 표시한다.

이 결함은 TF-BUG-006의 `reviewId=null` 요청 처리 예외와 다르다. TF-BUG-006은 대상 리뷰 식별자 검증 문제이고, TF-BUG-014는 유효한 리뷰에서 댓글 내용 경계 안내가 손실되는 UI 문제다.

## 8. 영향과 심각도 근거

- 백엔드가 입력을 거부하더라도 사용자는 무엇을 수정해야 하는지 알 수 없다.
- 정상 길이 댓글 작성과 데이터 무결성 실패는 확인되지 않아 `Minor`를 제안한다.

## 9. 수정 후 재검증 조건

- 1자·2자·100자·101자와 공백 전용 댓글을 확인한다.
- 프런트 사전 검증 또는 API 오류 매핑을 통해 동일한 2~100자 안내를 표시하는지 확인한다.
- 경계 위반 댓글이 목록에 추가되거나 댓글 수를 증가시키지 않는지 확인한다.
- 정상 2자·100자 댓글 작성이 회귀하지 않는지 확인한다.

## 10. 확인 한계

- 원본 수동 화면에서는 정확한 HTTP 상태와 오류 본문이 확인되지 않았으나 후속 Playwright trace에서 HTTP 400과 일반 오류 dialog를 확인했다.
- 제품 수정 후 구체적인 2~100자 안내가 표시되는 Pass 재검증은 아직 수행하지 않았다.
