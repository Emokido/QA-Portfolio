# TF-BUG-011 — 동행 모집 초장문 검색이 통제된 결과 대신 조회 오류로 종료됨

- 결함 상태: `Open`
- 발견 경로: 사용자 수동 프런트 탐색
- 기준 프로젝트: 스프린트 1 Java/Spring 완성본과 Next.js 프런트
- 기준 커밋: `e2431223ce2a18c8f944d544cba76b951ce0356d`
- 영향 기능: 동행 모집 검색의 키워드 입력 경계·오류 처리
- 테스트 수준: Browser UI · 정적 코드 상관 분석
- 심각도: `Minor`
- 수정 우선순위: 제품 담당자 결정 필요
- 실행 주체: `User`

## 1. 요약

동행 모집 검색창에 공백 포함 11,177자 키워드를 넣어 검색하면 빈 검색 결과나 입력 안내 대신 `모집 글을 불러오는 중 오류가 발생했습니다.`가 표시된다. 새로고침 후에는 기존 화면으로 돌아온다.

## 2. 원본 기록과 추적

- 수동 탐색 원본 번호: `BUG-003`
- 원본 발견 기록: 사용자 내부 자료로 보존하며 공개 산출물은 아래 정제 보고서를 사용한다.
- 수동 탐색 보고서: [TripFriend 수동 프런트 탐색 보고서](../reports/manual-frontend-exploration-report.md)

## 3. 테스트 환경과 데이터

- Windows 11, Chrome
- Frontend `localhost:3000`, Backend `localhost:8080`
- 로그인 및 로그아웃 상태
- 키워드: 공백 포함 11,177자·17,702바이트, 공백 제외 8,248자·13,994바이트

## 4. 재현 절차

1. `여행 동행 찾기`의 모집 목록으로 이동한다.
2. 검색창에 위 초장문 데이터를 입력한다.
3. 검색을 실행한다.
4. 화면과 Console 또는 Network 결과를 확인한다.

## 5. 기대 결과

지원 가능한 길이를 넘는 입력이면 검색 전에 제한과 수정 방법을 안내한다. 서버에 전달하는 정책이라면 요청을 통제된 클라이언트 오류 또는 정상 빈 결과로 처리하고 화면 전체를 일반 조회 오류로 전환하지 않는다.

## 6. 실제 결과

화면에 `모집 글을 불러오는 중 오류가 발생했습니다.`가 표시되고 사용자는 fetch 실패를 관찰했다.

## 7. 코드 상관관계

- `frontend/src/app/recruit/list/ClientPage.tsx`는 키워드 길이를 검사하지 않고 `searchAndFilterRecruits`에 전달한다.
- `frontend/src/lib/api/recruit.ts`는 `URLSearchParams`로 쿼리를 만들고 `/recruits/search3` 요청이 성공 상태가 아니면 일반 Error를 던진다.
- 화면은 이 예외를 단일 일반 오류 문구로 변환한다.

## 8. 영향과 심각도 근거

- 비정상적으로 긴 입력에서만 관찰됐고 새로고침으로 복구 가능하다.
- 데이터 손상이나 정상 길이 검색 실패는 확인되지 않아 `Minor`를 제안한다.

## 9. 수정 후 재검증 조건

- 제품이 지원하는 키워드 최대 길이를 정의한다.
- 경계값과 경계 초과 입력에서 입력 제한 또는 통제된 오류 안내를 확인한다.
- 정상 키워드와 결과 없음 검색이 회귀하지 않는지 확인한다.
- URL·서버·프록시별 길이 제한에 의존한 비결정적 실패가 없는지 확인한다.

## 10. 확인 한계

- 허용 최대 길이는 명시되지 않아 11,177자를 정상 허용해야 한다고 주장하지 않는다.
- 정확한 HTTP 상태와 실패 계층은 원본 기록에서 확인되지 않았다.
- Codex가 제품을 재실행하지 않았다.
